## 0. 直近目標の設定: BSCP（Burp Suite Certified Practitioner）

バグバウンティ学習の直近目標として、BSCP（Burp Suite Certified Practitioner）の取得を設定した。

### BSCP を選んだ理由（OSCPとの比較）

| 項目 | BSCP | OSCP |
|---|---|---|
| 対象範囲 | Webアプリケーションのみ（XSS/SQLi/IDOR/SSRF等） | ネットワーク・サーバ全体（OS権限昇格、Active Directory、内部ネットワーク侵入等を含む） |
| 試験時間 | 4時間 | 24時間（実技）+レポート提出 |
| 費用 | $99（+Burp Suite Pro が必要な場合 $449/年） | 高額（コース込みで $1,500〜2,000 程度、時期・プランにより変動） |
| 有効期限 | 5年間 | 3年間 |
| バグバウンティ（Web中心）との相性 | ◎ ほぼ完全一致 | △ 範囲が広く迠回りになりやすい |

現在取り組んでいるPortSwigger Web Security Academyの学習内容が、そのまま BSCP の試験対策になる（試験問題はWeb Security AcademyのPractitionerレベル以下のラボを改変したものがランダム出題される、という実際の合格者の報告あり）。この整合性の高さから、BSCP を直近目標とした。

### BSCP 試験概要（参考情報）

- 試験時間: 4時間
- 費用: $99（別途 Burp Suite Pro Edition が必要な場合あり、無料トライアルでも受験可）
- 有効期限: 5年間
- 受験予約: 不要、好きな時間に受験可能
- 再受験制約: なし

## 1. 前提条件

- 基礎学習（SQLi/IDOR/XSS/SSRFの基礎ラボ）は約20〜30時間で完了想定（別記事のトレーニングプラン範囲）
- そこからBSCP試験対策として深掘りする総学習時間を **約150〜200時間** と設定
  - 実際の合格者の実測値（総学習時間約450時間）より短めに設定。理由は、既存のクラウド/インフラ実務経験を活かし、SSRFやアクセス制御（IDOR）分野の学習を短縮できる見込みのため
- 学習は基本的に週末（土日）のみ実施

## 2. 3ヶ月パターン（短期集中）

**週あたり学習量:** 約12〜15時間（土日各６〜７時間）

| 月 | 内容 |
|---|---|
| 1ヶ月目 | 基礎4テーマ（SQLi/IDOR/XSS/SSRF）を集中的に周回。Burp Suiteの操作にも慣れる |
| 2ヶ月目 | 残りのトピック（CSRF、XXE、認証、SSTI、JWT等）を一通りカバー。Exam preparation steps（公式の受験前チェックリスト）に着手 |
| 3ヶ月目 | Practitionerレベルラボの模擬演習・総復習。3ヶ月目後半にBSCP受験 |

**評価:** 週末に1日６〜７時間はほぼ土日を丸々学習に使うレベルで、負荷が高い。最短距離だが、転職活動や体力面との両立が厳しい可能性がある。

## 3. 6ヶ月パターン（現実的なペース・推奨）

**週あたり学習量:** 約6〜7.5時間（土日各３〜４時間）

| 月 | 内容 |
|---|---|
| 1ヶ月目 | 基礎4テーマ（SQLi/IDOR/XSS/SSRF）を集中学習 |
| 2ヶ月目 | Access control・認証・CSRF等、頻出トピックを追加 |
| 3ヶ月目 | XXE・SSTI・JWT・Web LLM攻撃など応用トピック |
| 4ヶ月目 | 苦手分野の復習＋実践（HackerOne/Intigriti）を並行開始し、実戦感覚を養う |
| 5ヶ月目 | Practitionerレベルラボの総復習、Exam preparation steps完了 |
| 6ヶ月目 | 模擬演習・弱点補強。6ヶ月目後半にBSCP受験 |

**評価:** 1日３〜４時間は集中すれば無理のないライン。転職活動との両立がしやすく、継続しやすい現実的なペース。

## 4. 比較まとめ

| | 3ヶ月パターン | 6ヶ月パターン |
|---|---|---|
| 週あたり学習量 | 週12〜15時間（1日６〜７時間） | 週６〜７.5時間（1日３〜４時間） |
| 負荷 | 高い（ほぼ土日全部） | 中程度（無理のない範囲） |
| 転職活動との両立 | 厳しい可能性あり | 両立しやすい |
| 継続のしやすさ | 息切れリスクあり | 続けやすい |

転職活動という別の大きなタスクと並行して進める前提のため、6ヶ月パターンを基本推奨としつつ、実際の進捗次第でペースを調整する運用とした。
