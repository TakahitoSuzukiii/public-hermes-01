# バグバウンティ学習ログ #1: 開始〜環境準備・トレーニングプラン策定

## 0. 背景

個人の学習・スキルアップとして、バグバウンティ（脆弱性報奨金制度）への挑戦を開始した。目標は座学に留まらず、実際にHackerOne / Intigritiで有効な脆弱性を報告し、実践で通用する力をつけること。

参考ガイド: `docs/info/security/` 配下のバグバウンティ入門資料（別記事）。

## 1. 完了したこと

### 1-1. プラットフォームへのアカウント登録
- **HackerOne**（https://www.hackerone.com/）: 登録完了
- **Intigriti**（https://www.intigriti.com/）: 登録完了、2要素認証（MFA）も設定済み

これらは「実際に脆弱性を探して報告する本番の場」。今はまだ基礎学習中のため、いきなり挑戦するのではなく、まず練習環境で型を身につける方針とした。

### 1-2. 練習環境の選定・登録
- **PortSwigger Web Security Academy**（https://portswigger.net/web-security）に登録
- 選定理由:
  - 完全無料
  - 実際に脆弱性が仕込まれた練習用サイト（ラボ）で手を動かして学べる
  - SQLインジェクション・XSS・アクセス制御（IDOR）・SSRFなど、実務直結のテーマが揃っている
  - 日本語の解説記事（Writeup）が豊富で、詳まった時に参照しやすい

## 2. トレーニングプランの策定

「ドキュメントを読み込んで理解する」学習スタイルより、「まず手を動かして、詳まったら覚える」実践型のスタイルが合っているとの自己認識に基づき、以下の方針でプランを策定した。

### 2-1. PC / スマホの役割分担

学習環境として、PC（自宅等でまとまった時間）とスマホ（すきま時間）の両方を使うため、それぞれの得意なことに役割を分けた。

| 環境 | 役割 | 理由 |
|---|---|---|
| **PC** | 実弾訓練（メイン） | PortSwiggerのラボ攻略には「Burp Suite」というPC専用の通信解析・改ざんツールが本質的に必要。スマホだけでは学習効果が薄い |
| **スマホ** | インプット・偵察（サブ） | 過去のWriteup記事を読む、HackerOne/Intigritiの公開された過去のバグ報告（Hacktivity）を眺める、挑戦したいプログラムのスコープを事前に読んでおく |

### 2-2. 「これだけやればOK」という基礎ラインの設定

全ラボ制覇を目指さず、以下4テーマ・合計15〜20ラボ程度を最初のゴールとした。

| 順番 | テーマ | 目安ラボ数 | 選定理由 |
|---|---|---|---|
| 1 | SQLインジェクション（基本編） | 3〜4問 | 型がシンプルで、Burp Suiteの基本操作を覚えやすい |
| 2 | アクセス制御（IDOR） | 3〜4問 | クラウド/インフラ運用経験と直結し、強みを活かしやすい |
| 3 | クロスサイトスクリプティング（XSS） | 4〜5問 | バグバウンティで最頻出のカテゴリ | 
| 4 | SSRF | 3〜4問 | クラウド環境の構成ミスと関連が深く、実務経験が活かす分野 |

### 2-3. 各ラボの取り組み方（実践優先サイクル）

1. タイトルと問題文だけ読む（30秒）
2. とりあえず操作してみる（5〜10分、分からなくてよい）
3. 詳まったら解答（Solution）を見て理解する（根性で解く必要はない）
4. 納得したら次のラボへ（復習は後回しでよい）

この方式なら1ラボあたり10〜15分で回せる計算のため、4テーマ。15〜20ラボはトータル3〜5時間程度で一周できる見込み。

### 2-4. 実践（HackerOne/Intigriti）への移行タイミング

上記4テーマを一通り触った時点で、完璧を待たずに実践へ移行する方針とした。最初はIntigritiの小規模プログラムから、IDORとSSRF（クラウド構成ミス系）を優先的に探す方針で、既存のクラウド/インフラ経験を活かす。

## 3. 次のアクション

- Burp Suite Community Edition（無料版）をPCへインストール
- SQLインジェクションの基礎ラボから着手

## 4. まとめ

座学中心ではなく、練習環境（PortSwigger）で手を動かしながら型を身につけ、最短距離で実践（HackerOne/Intigriti）に進むことを重視した計画とした。今後の進捗は本シリーズのドキュメントとして随時記録・公開していく。
