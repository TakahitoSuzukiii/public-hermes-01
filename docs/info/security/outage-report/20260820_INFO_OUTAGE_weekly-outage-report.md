# 週次まとめ: AWS US-WEST-2接続障害（4か月で4件目）とMicrosoft 365検索障害継続（2026-08-20）

## 🌐 メガテック系

### 1. AWS「US-WEST-2」リージョンでの接続障害（4か月で4件目）
- **発生日:** 2026年8月15日頃（報道確認: 8月中旬〜下旬）
- **対象サービス:** AWS（Amazon Web Services、Amazonが提供するクラウドサービス）の米国西部「US-WEST-2」リージョン（データセンターが立地する地域単位）における接続性の問題
- **原因:** 詳細な根本原因は現時点で公式に完全開示されていない。報道では過去4か月で同種の障害が4回目と指摘されている
- **影響範囲:** US-WEST-2リージョンを利用するサービス・アプリケーションで断続的な接続障害。具体的な影響ユーザー数は未公表
- **復旧状況:** 報道時点で対応済みとされているが、AWS公式ステータスページでの正式な事後報告（ポストモーテム）は本記事作成時点で未確認
- **出典:** https://tech-insider.org/aws-outage-us-west-2-2026/ , https://servicealert.ai/outage-reports/aws-outage-2026-08-15

### 2. Microsoft 365「検索」機能の障害（前週から継続）
- **発生日:** 2026年8月18日発生、対象期間終盤まで継続中（前週レポートで既報）
- **補足:** Outlook / SharePoint Online / OneDrive の検索機能に影響する障害で、前週（8/19付レポート）に続報として掲載済みのため、本記事では詳細の重複掲載を省略します。8月21日午前4時（UTC）に評価チェックポイントが予定されているとの情報があり、引き続き注視が必要な状況です
- **出典:** https://cybersecuritynews.com/microsoft-365-search-outage/
