# 週次まとめ: Microsoft 365検索障害・GitHub世界的障害・Slack一部機能停止（2026-08-19）

## 🌐 メガテック系

### 1. Microsoft 365「検索」機能の障害（Outlook / SharePoint / OneDrive）
- **発生日:** 2026年8月18日（発生中、8月21日午前4時 UTC に評価チェックポイント予定）
- **対象サービス:** Outlook on the web、Outlook デスクトップ、SharePoint Online、OneDrive の検索機能
- **原因:** Microsoft は「検索インデックス（検索対象データの索引情報）」関連の不具合と説明。詳細な根本原因は現時点で完全開示されていない
- **影響範囲:** 世界中の Microsoft 365 利用者。メール・ファイル検索が正常に動作しない、または結果が表示されない事象
- **復旧状況:** 記事執筆時点（本記事対象期間末）で対応中。Microsoft Service Health（サービスの稼働状況を公式に通知する管理画面）にてインシデントとして継続追跡中
- **出典:** https://cybersecuritynews.com/microsoft-365-search-outage/ , https://www.bleepingcomputer.com/news/microsoft/microsoft-working-to-fix-bug-behind-microsoft-365-search-issues/

### 2. GitHub の世界的な障害
- **発生日:** 2026年8月17日
- **対象サービス:** GitHub（リポジトリのアーカイブダウンロード、raw ファイル取得など）
- **原因:** 詳細未公表。報道では特定機能のエラー率上昇が中心
- **影響範囲:** アーカイブダウンロードや raw リポジトリコンテンツ取得で約50%のエラー率発生と報告。世界中の開発者が影響を受けたとされる
- **復旧状況:** 報道時点で継続中との記載あり。その後の完全復旧は本記事執筆時点で公式発表未確認
- **出典:** https://cybersecuritynews.com/github-outage-worldwide/

### 3. Slack の一部機能停止（データ保持処理）
- **発生日:** 2026年8月18日
- **対象サービス:** Slack（独自のメッセージ保存期間設定を行っている一部チャンネルのデータ保持処理）
- **原因:** 未公表
- **影響範囲:** 該当設定を行っている一部顧客に限定。Slack全体の利用停止ではない
- **復旧状況:** 8月18日6時57分ごろ時点で復旧作業継続中と案内
- **出典:** https://funshitsu.com/status/

## 所感

今週はメガテック側でMicrosoft 365・GitHub・Slackと立て続けに障害報道があり、開発者向けインフラ（コード管理・コミュニケーションツール）への依存度の高さが改めて浮き彫りになりました。特にGitHubの障害はCI/CD（継続的インテグレーション・継続的デリバリー、コードの自動テスト・配信の仕組み）パイプラインに直結するため、業務影響が大きかったと推測されます。一方、日系企業側は対象期間内の新規大規模障害は確認されず、直近では日本郵便やニチレイなど「物流・データ連携」領域での障害が目立った週の余波が続いている状況です。クラウド依存が進む中、単一障害点（SPOF: Single Point of Failureの略、システム全体を止めうる一箇所の弱点）をどう分散するかが、引き続き業界共通の課題と言えそうです。
