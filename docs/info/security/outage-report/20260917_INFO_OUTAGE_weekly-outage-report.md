# 週次まとめ：メガテック企業・日系IT大手のシステム障害

このレポートは、直近7日間に発生・報道された大規模障害情報をWeb検索で収集し、要約したものです（個別サイトの全文転載は行わず、出典URLを明記しています）。

## 🌐 メガテック系

### Microsoft 365：Outlook/Teams等で502/503エラーが多発
- **発生日**: 2026年9月16日夜（米国時間）〜継続中（報道時点）
- **対象サービス**: Microsoft 365スイート全般（Outlook、Teams等の中核アプリ含む）
- **原因**: 公式には詳細未発表。ユーザーから「502」「503」エラー（＝サーバー側の過負荷や中継エラーを示すHTTPエラーコード）の報告が世界的に多発
- **影響範囲**: 世界中のユーザーがMicrosoft 365の中核アプリにアクセスできない状態
- **復旧状況**: 報道時点（9月16日）では対応中。その後の完全復旧は本レポート執筆時点で未確認
- **出典**: https://cybersecuritynews.com/microsoft-365-hit-by-new-outage/

### Salesforce：グローバルで大規模障害、PayPayの入力フォームにも影響
- **発生日**: 2026年9月16日夕方（日本時間）
- **対象サービス**: SalesforceのCRM（顧客関係管理＝顧客情報や営業活動を一元管理するクラウドサービス）を中心とした中核サービス
- **原因**: 公式ステータスページで障害を認めているが、根本原因の詳細は記事内では確認できず
- **影響範囲**: グローバル規模。日本ではPayPayが提供する一部フォームにも影響が及んだと報道
- **復旧状況**: 報道時点で対応進行中。完全復旧時刻は未確認
- **出典**: https://www.itmedia.co.jp/news/article/2609/16/2000001562/

### AWS：一部リージョンでEC2/S3/DynamoDB等のエラー率上昇
- **発生日**: 2026年9月16日
- **対象サービス**: AWS Health Dashboardの記載によれば、2つのリージョンにまたがりEC2（仮想サーバー）、S3（オブジェクトストレージ）、DynamoDB（NoSQLデータベース）、Lambda（サーバーレス実行環境）、Kinesis、CloudWatch、RDS、およびマネジメントコンソール／CLIで影響
- **原因**: AWS公式ダッシュボードの記載は「elevated error rates and degraded availability（エラー率上昇・可用性低下）」にとどまり、対象リージョン名や根本原因の詳細はソースから確認できませんでした
- **影響範囲**: 該当リージョン内でAPIエラーや新規インスタンス起動失敗など。既存の稼働中インスタンスへの影響は限定的との記載あり
- **復旧状況**: 検索時点の情報のみで、復旧完了の確認は取れていません
- **出典**: https://health.aws.amazon.com/health/status , https://statusgator.com/services/amazon-web-services/outage-history
- **注記**: 本件は情報源が限定的（詳細な一次情報の全文取得ができず）のため、確度は中程度と評価しています。

### Cloudflare：局所的な小規模インシデント複数
- **発生日**: 2026年9月15日〜16日にかけて断続的
- **対象サービス**: Cloudflare Queues（メッセージキューサービス）、LAX（ロサンゼルス）・PHX（フェニックス）の各データセンター
- **原因**: 個別インシデントごとに詳細は記載されているが、いずれも「Minor（軽微）」区分
- **影響範囲**: 特定リージョン・特定機能に限定。グローバルなサービス断は発生していない模様
- **復旧状況**: 各インシデントとも「Completed／Resolved」表記あり
- **出典**: https://www.cloudflarestatus.com/history

## 所感（今週の傾向）

今週は日系企業単独の重大障害こそ確認されませんでしたが、Salesforceのグローバル障害がPayPayの一部機能に波及した事例が象徴的でした。クラウド基盤・SaaS（Software as a Service＝ソフトウェアをネットワーク経由で提供する形態）に依存する国内サービスは、海外プラットフォーマー側の障害の影響を直接受けるリスクを常に抱えていることが改めて浮き彫りになった週と言えます。また、Microsoft 365やAWSでもエラー率上昇の報告があり、大手クラウド事業者側でも局所的な不安定さが続いている印象です。ただしAWSの件は一次情報の裏付けが弱く、続報があれば来週以降のレポートで補足します。
