# 週次システム障害まとめ(2026-11-06〜11-12)

※ 出典は各社公式発表・報道・障害監視サイト。内容は筆者(Prime)が要約。原因が未公表のものは「未確認」と明記。

## 🌐 メガテック系

### 1. AWS(米国西部・オレゴン us-west-2)EC2のインスタンス起動失敗(2026-11-07 JST)
- **対象サービス:** Amazon EC2(仮想サーバーを借りるサービス)、EBS(サーバー用ディスク)、DataSync / AWS Backup(データ転送・バックアップ機能)
- **原因:** EBSの「インスタンス起動時に必要なサブシステム」の不具合(AWSステータス記載。さらに詳しい原因は未確認)
- **影響:** us-west-2の全アベイラビリティゾーン(データセンター群の区画)で新規サーバーの起動が失敗。**すでに稼働中のサーバーとEBSは影響なし**。
- **復旧:** 太平洋時間 14:35〜16:21(約1時間46分)で完全復旧。
- **出典:** https://uptimus.app/status/service/aws/outage-history

### 2. Apple iCloud / Apple Account 障害(2026-11-11 JST)
- **対象サービス:** iCloudのサインイン、カレンダー、メール、連絡先、iWork、写真、Game Center、「探す」
- **原因:** 未公表(確認できず)
- **影響:** iPhone/MacでApple Accountのログイン・設定更新を求められる不具合が出た。
- **復旧:** 7:49〜9:22(「探す」のみ〜9:54)に解消。
- **出典:** https://news.mynavi.jp/techplus/article/20261111-5299554/

### 3. Cloudflare の軽微な障害(2026-11-10)
- **対象サービス:** Workersのイベント購読、分析ダッシュボード、セントルイス拠点のネットワーク性能など計4件(CDN=コンテンツ配信網を提供する企業)
- **原因・影響:** 軽微(Minor)扱い。詳細な原因は未確認。
- **復旧:** 一部は監視サイト調査時点で未解決の記載あり。
- **出典:** https://uptimerobot.com/is-it-down/cloudflare/2026-11-10/

## 🇯🇵 日系企業系

### 1. NTTドコモ 5G SA 通信障害(2026-11-11)※11/5に続き2回目
- **対象サービス:** 5G SA(Standalone=5G専用設備だけで通信する方式)契約者の音声通話・データ通信・SMS
- **原因:** 5G SA契約者を収容する交換機の輻輳(ふくそう=処理が集中してパンク)。ドコモは不正アクセス・サイバー攻撃の形跡なしと説明。前回(11/5)は保守作業中の交換機メモリ異常が引き金で、今回の引き金は未説明。
- **影響:** 全国。通常の5G・4G、ドコモ回線のMVNO、緊急通報は影響なし。「圏外」表示になる場合あり。前回は最大約158万人に影響。
- **復旧:** 10:34〜19:17(約8時間43分)。復旧しない場合は再起動または機内モードON/OFF。4Gに切替えていた場合は元に戻す。
- **出典:** https://www.docomo.ne.jp/info/network/kanto/pages/261111_13_m.html / https://www.asahi.com/articles/ASVCC108NVCCULFA00TM.html

### 2. しんきん共同センター(信用金庫の勘定系)障害(2026-11-06)
- **対象サービス:** 東海以西の128信用金庫の窓口業務、ATM、インターネットバンキング(勘定系=預金・振込を処理する基幹システム)
- **原因:** ホストコンピューターの故障
- **影響:** 各地の信金で一斉に取引不能。
- **復旧:** 19時過ぎに全面復旧。
- **出典:** https://biz.chunichi.co.jp/news/article/10/132954/

### 3. 日本郵便 UGX送り状作成システム「Hubez」等の緊急メンテナンス(11/11時点で継続)
- **対象サービス:** 国際物流UGXの送り状作成システムと関連システム(出資先のレントングループ提供)
- **原因:** 未公表(確認できず)
- **復旧:** システム自体は復旧済みだが、安全な再開のためなお期間を要する見込み。再開時期は未定。

## 所感(今週の傾向)
- ドコモは「対策完了を宣言した5日後に同種の障害が再発」という形。1回目の原因を潰しきれていないか、別要因の可能性があり、今後の原因報告に注目です。
- 信金の勘定系や日本郵便など、**共同利用・外部委託先のシステムに依存した障害**が目立ちました。1か所の不具合が多数の事業者に波及する構造です。
- 海外はAWSの限定的な障害とApple・Cloudflareの軽微なものが中心で、大規模事案は小康状態でした。
