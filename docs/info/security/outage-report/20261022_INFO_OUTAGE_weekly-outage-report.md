# 週次システム障害まとめ(2026-10-16〜10-22)

今週は「巨大クラウドの全面停止」はなく、Cloudflareの小〜中規模障害が続いた週でした。日本側では、金融機関向けアプリ基盤の障害と、プログラミング言語PHPの重大な脆弱性(セキュリティ上の欠陥)に伴う緊急メンテナンスが目立ちました。

## 🌐 メガテック系

### 1. Cloudflare: 小〜中規模の障害が週を通して複数発生(10/18〜10/21)
- 対象サービス: Cloudflare(CDN＝世界中のサーバーでWebを高速配信する仕組み、DNS＝ドメイン名をIPアドレスに変換する仕組み、Zero Trust＝社内システムへの安全な接続サービス)
- 確認できた事象(いずれも復旧済み):
  - 米国2拠点を経由する通信の遅延(10/18 約17:00〜17:50に復旧)
  - DNS更新の遅延(10/19 20:50に復旧)
  - Zero Trustの接続障害(10/20 15:32に復旧)
  - 認証済みボット(身元確認済みの自動巡回プログラム)の一部を誤って分類する問題(10/21 5:16に復旧)
  - Gemini向けの利用制御・DLP(情報漏えい防止機能)の問題(10/21 7:46に復旧)
- 原因: 詳細は公式の事後報告待ち。確定情報は未確認。
- 影響範囲: 限定的(特定拠点・特定機能)。全面停止の報告なし。
- 出典: https://funshitsu.com/status/ (公式情報の確認先をまとめた国内サイト)

### 2. PHPの重大な脆弱性に伴う緊急措置(10/21〜)
- 内容: PHP(Webサイト開発で広く使われるプログラミング言語)に深刻度「Critical」の脆弱性が見つかり、修正版が公開された。これを受け、静岡銀行がネットバンキングを一時停止、七十七銀行など東北の地銀も一部サービスを停止、鉄道会社などでも緊急措置が取られた。
- 影響: 全国銀行協会は、銀行間の決済関連への影響は確認されていないと説明。障害というより「予防的な停止」。
- 復旧状況: 報道時点(10/21〜22)では対応中の事業者あり。再開状況は各社の告知を要確認。
- 出典:

## 所感(今週の傾向)
- 巨大クラウドは静かな一方、Cloudflareは小さな障害が毎日のように出ていました。CDNやZero Trustのように「入口」を担うサービスは、一部の不調でも利用者に影響しやすい点に注意が必要です。
- 国内ではPHP脆弱性への「予防的な停止」が大きな動きでした。障害は故障だけでなく、脆弱性対応でも起きます。使用言語・ライブラリの更新情報を継続的に追う運用が重要です。
- 金融系は共通基盤(アプリ基盤、外部接続先)の不具合が複数の事業者に波及する構造が、前週のPayPay証券に続いて再度見られました。
