## 用語ミニ解説（初心者向け）

- **デジタルウォレット（digital wallet）**: スマホアプリ内でお金を保管・送受金・決済できる「電子的な財布」。
- **P2P 送金（Peer-to-Peer＝個人間送金）**: 銀行を介した振込ではなく、アプリ上でユーザー同士が直接お金を送り合う仕組み。
- **APY（Annual Percentage Yield＝年利回り）**: 預けたお金に対して1年間で付く利息の割合（複利込み）。
- **FDIC（Federal Deposit Insurance Corporation＝米連邦預金保険公社）**: 米国の預金保険。銀行破綻時に預金を一定額まで保護する。
- **Money Transmitter License（MTL＝資金移動業ライセンス）**: 米国で送金・決済事業を行うために州ごとに必要な免許。
- **Visa Direct**: Visa が提供する「リアルタイム資金移動」基盤。デビットカード経由で即時に送金・着金できる。

## 1. 概要（What is X Money?）

**X Money** は、**X（旧 Twitter）アプリの中に組み込まれたデジタルウォレット（決済・金融サービス）**です。運営は X Corp.（決済子会社は X Payments LLC）。SNS を離れずに、以下を1つのアプリで完結できるのが狙いです。

- **お金を保管**（USD 残高をアプリ内で保持）
- **送受金**（@ハンドル宛に P2P 送金）
- **利息を得る**（残高に対し約 **6% APY**）
- **決済する**（専用の **Visa デビットカード**）

Elon Musk 氏が掲げる「**Western WeChat（西側版 WeChat）＝SNS＋決済のスーパーアプリ化**」構想の中核。X と **Visa の提携**は 2025-01-28 に公式発表され、**Visa Direct** を使って「デビットカードからのウォレット入金」「P2P 送金」「銀行口座への即時出金」を実現します。

- 参考: [X × Visa 提携発表（AP, 2025-01-28）](https://apnews.com/article/ed4538e0be2deb5fb5767ffb39ba25f3) / [CNBC](https://www.cnbc.com/2025/01/28/elon-musk-x-visa-digital-wallet.html) / [TechCrunch](https://techcrunch.com/2025/01/28/x-announces-a-partnership-with-visa-for-to-power-x-moneys-wallet/)

## 5. 始め方（登録の骨子）※米国居住者前提

1. **X の有料プラン（Premium / Premium+）に加入**し、アカウントを本人認証（KYC）。
2. X アプリ内の **「Money」セクション** を開く（未提供地域ではウェイトリスト登録のみ）。
3. **本人確認（氏名・住所・SSN 等）** を行い、ウォレットを開設。
4. **入金**：デビットカード（Visa Direct）連携／銀行口座／給与の直接入金（direct deposit）で残高をチャージ。
5. **Visa デビットカード（名入りメタル）を申請** し受領。
6. **P2P 送金**：相手の @ハンドル宛に送金。着金は Visa Direct で即時反映。

> 日本居住者は現状 **ウェイトリスト登録まで**。実際の口座開設・本人確認は日本正式対応後の想定。

## 6. 運用（日常の使い方・注意点）

- **残高を置くだけで約6% APY**（最低残高なし）。給与を直接入金すれば初日から利息対象との報道。
- **決済**：Visa デビットで支払うと **3% キャッシュバック**、**海外手数料ゼロ**。
- **送受金**：@ハンドル宛に即時 P2P。クリエイター報酬は即時着金・当日利用可（2026-07 更新）。
- **請求書払い（bill pay）** にも対応し「アプリ内の銀行口座」的に使える設計。
- **セキュリティ運用の基本**：X アカウント自体の乗っ取り＝資金流出に直結するため、**強固なパスワード＋二段階認証（2FA）** 必須。フィッシング（偽の「X Money」案内）に注意。
- **暗号資産（Bitcoin/Doge 等）は初期ローンチに非搭載**。将来対応は未確定。

## 7. リスク・注意点

- **規制・地域制限**：米国のみ。NY・MA は未対応。日本は未提供（時期未確定）。
- **金利変動**：6% APY は現時点のプロモ的水準。将来引下げ・条件変更の可能性。
- **保護の範囲**：FDIC 保護は提携銀行（Cross River Bank）の預金に対するもの。**X は銀行そのものではない**点に留意。
- **為替**：日本から使う場合（将来）、USD 建てのため為替変動リスク。
- **詐欺・セキュリティ**：新興・話題のサービスは偽サイト／偽アプリ／偽キャンペーンの標的になりやすい。**公式 X アプリ内からのみ操作** する。
- **情報の鮮度**：本稿は二次情報中心（公式ヘルプは 403 で直接取得不可）。数値・条件は **必ず公式で最新確認** を。
